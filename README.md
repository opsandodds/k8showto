# K8s How-To — Ops & Odds

Follow-along source for the **Ops & Odds** Kubernetes How-To series. Every episode
is a real, do-it-yourself tutorial you can run on your own laptop with
[k3d](https://k3d.io/) — no cloud account needed.

## Episodes

| # | Topic | Folder |
|---|-------|--------|
| 1 | Observability: logs, metrics & traces with the Grafana stack | [`ep01-observability/`](ep01-observability/) |
| 2 | Autoscaling with the Horizontal Pod Autoscaler | [`ep02-autoscaling/`](ep02-autoscaling/) |
| 3 | GitOps with ArgoCD | [`ep03-gitops/`](ep03-gitops/) |

Each folder has its own README with the exact commands from the video.

## Prerequisites (all episodes)

- [Docker](https://docs.docker.com/get-docker/)
- [k3d](https://k3d.io/) · [kubectl](https://kubernetes.io/docs/tasks/tools/) · [helm](https://helm.sh/)
